# samarthraina.github.io

Personal research website for Samarth Raina.

The site is intentionally static and dependency-free. It contains:

- a research-focused homepage;
- a project index and detailed pages for core research;
- Writing, Reading Notes, and Thinking sections;
- an About page; and
- a reserved portrait slot.

## Adding the portrait

Add the final image at `assets/profile.jpg`. A styled initials card is shown until that file exists.

## Updating writing and reading

The current pages contain intentional coming-soon states. Replace those sections as the first articles and reading notes are published.
